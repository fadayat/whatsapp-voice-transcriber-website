Security & Technical Architecture

Designed specifically to prevent WhatsApp Web chat scraping, audio eavesdropping, and plain-text credential leaks.

01

MAIN-World Detached Audio Hook

WhatsApp Web isolates decrypted voice streams in headless JavaScript Audio instances rather than DOM audio tags. The extension intercepts the in-memory blob: URL at document start, sets media volume to zero, and resets position before dispatch.

02

Loopback-Only Node.js Helper

Third-party API credentials never touch browser storage or extension content scripts. Audio arrays pass through 127.0.0.1:4318 over a restricted loopback origin with strictly validated Opus/OGG headers.

03

Native OS Secret Storage

When persistent authentication is enabled, the Groq API key is written directly to the operating system credential vault (GNOME Keyring on Linux, macOS Keychain, or Windows Credential Manager) with filesystem mode 0600.

04

Account-Level Zero Data Retention

Inference uses Groq's Speech-to-Text endpoint under configured Zero Data Retention. Neither audio bytes nor textual output are stored on disk, logged in server output, or cached in cloud databases.

Setup & Deployment

Three steps to run the helper daemon and install the unpacked extension in Brave or Chrome.

1. Start Local Helper Daemon

Clone the open-source repository and start the local helper server. It binds strictly to 127.0.0.1:4318.

bash 
git clone https://github.com/fadayat/whatsapp-voice-transcriber.git
cd whatsapp-voice-transcriber
npm install
npm start

2. Load Extension in Browser

Open your browser extension manager and enable Developer Mode:

  1. Navigate to brave://extensions or chrome://extensions
  2. Toggle Developer mode in the upper right corner
  3. Click Load unpacked and select the repository's extension/ directory

3. Authorize via Local Setup Page

Navigate to http://127.0.0.1:4318/setup in your browser. Enter your Groq API key once. The helper verifies authentication against Groq and stores the credential in your system vault.
