A short, explicit data path.

The project minimizes what it handles, but cloud transcription still means sharing the selected audio with Groq.

  1. 1
    You choose one voice note

    The extension does not automatically transcribe a chat or collect text messages.

  2. 2
    WhatsApp prepares the audio

    The extension suppresses audible playback while capturing the selected note in memory. WhatsApp may still mark it as played.

  3. 3
    The local helper forwards it

    Audio and transcript data remain in memory in the helper and are not written to disk by this project.

  4. 4
    Groq performs transcription

    Enable Zero Data Retention in your Groq Console before private use and review Groq’s current data terms.

What is verified here

The repository includes automated tests for request validation, origin restrictions, silent capture, recycled WhatsApp rows, dark mode, and layout behavior.

Install the developer preview.

You need Node.js 22+, a Chromium browser, and your own Groq API key. The project is installed from source.

  1. 01
    Clone and start the helper

    Install its single production dependency, then run the local service.

  2. 02
    Load the extension

    Enable Developer mode and load the repository’s extension/ folder unpacked.

  3. 03
    Configure Groq locally

    Open the extension popup, choose Open secure setup, and save or use the key for the current session.

  4. 04
    Reload WhatsApp Web

    Select Transcript on a detected voice message.
