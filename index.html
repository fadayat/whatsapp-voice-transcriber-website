Privacy & Architecture

Engineered Specifically for Privacy

Standard transcribers forward chats to third-party servers. Voice Note Transcriber keeps everything private, client-side, and on-demand.

🤫

Silent DOM Hook

WhatsApp Web no longer exposes standard <audio> DOM tags. Our MAIN-world hook captures the decrypted in-memory Opus Blob URL, silences the playback channel, and resets media position instantly.

🔒

Zero Data Retention

Audio stays in temporary memory and is sent directly to your Groq endpoint. No audio bytes or text transcripts are written to disk, server logs, or cloud databases.

🔑

OS Credential Keyring

Your Groq API key is stored securely in your OS keychain (GNOME Keyring, macOS Keychain, or Windows Credential Manager). It never touches the browser extension storage or Git files.

🎯

User-Triggered Privacy Model

The extension never runs in the background across your entire chat. It only wakes up and transcribes the single message where you explicitly clicked "Transkript".

⚡

Whisper Large v3 Accuracy

Leverages OpenAI's benchmark Whisper Large v3 model running on Groq's high-performance LPU inference engine, giving 90+ language support with native Azerbaijani accents.

🎨

Seamless Native Bubble Fit

Mounts directly inside WhatsApp's real speech bubble with auto-adapting light/dark mode, scroll-recycle cleanup, and a dedicated 20px footer lane so message timestamps never collide.

Under The Hood

How It Works in 4 Steps

01

User Clicks Transcribe

You click the discreet inline Transkript button inside the voice message bubble.

02

Silent Blob Extraction

The MAIN-world hook extracts the in-memory decrypted Opus audio blob silently with zero speaker leak.

03

Local Helper Forwarding

Audio is forwarded to 127.0.0.1:4318, which attaches your OS-stored Groq key and queries Whisper.

04

Instant Inline Render

The transcript arrives in ~1.2s and mounts cleanly below the waveform with 1-click Copy.

Get Started in 2 Minutes

Quick Installation Guide

Works on Linux (Fedora/Ubuntu), macOS, and Windows with Brave, Chrome, or any Chromium-based browser.

Step 1 • Clone & Start Local Helper
# Clone repository
git clone https://github.com/fadayat/whatsapp-voice-transcriber.git
cd whatsapp-voice-transcriber

# Install dependencies & start helper (runs on 127.0.0.1:4318)
npm install
npm start
Step 2 • Load Unpacked Extension in Brave / Chrome
  • 1. Open brave://extensions or chrome://extensions in your browser.
  • 2. Toggle on "Developer mode" in the top-right corner.
  • 3. Click "Load unpacked" and choose the extension/ folder in the cloned repo.
Step 3 • Add Free Groq Key to Secure OS Keyring

Open http://127.0.0.1:4318/setup in your browser. Paste your free Groq API key (starts with gsk_...). The helper verifies the key and securely saves it in your system credential vault.
