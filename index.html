Engineering & Privacy Pillars

Built from the ground up to prevent data leaks, eliminate speaker sound, and maintain local device sovereignty.

Silent In-Memory Hook

WhatsApp Web creates detached, headless Audio objects for decrypted voice messages. The extension captures the blob URL in memory, mutes volume to 0%, and resets position to avoid speaker playback.

Account-Level Zero Retention

Sends verified audio payloads directly to Groq Speech-to-Text running Whisper Large v3. Neither audio bytes nor textual transcripts are ever saved to disk or retained by cloud servers.

OS Keyring Encryption

Your Groq API key is stored locally in your operating system's native credential vault (GNOME Keyring, macOS Keychain, or Windows Credential Manager). It never touches browser storage.

Quick Installation

Set up the local helper daemon and install the unpacked extension in Brave or Chrome.

01

Start Local Loopback Server

Clone the repository and launch the Node.js helper (runs strictly on 127.0.0.1:4318):

git clone https://github.com/fadayat/whatsapp-voice-transcriber.git
cd whatsapp-voice-transcriber
npm install
npm start
02

Load Extension in Browser

Go to brave://extensions or chrome://extensions, enable Developer mode, click Load unpacked, and select the extension/ folder.

03

Save API Key in OS Vault

Visit http://127.0.0.1:4318/setup in your browser. Enter your Groq API key to store it securely in your system keyring.
